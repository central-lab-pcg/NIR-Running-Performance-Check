NIR X-Chart (Control Chart) Tool

Plot กราฟควบคุมคุณภาพ (X-Chart) ของ Control Sample (QC) แยกตามแต่ละ Parameter

ตั้งค่า Chart

หมายเหตุ: เกณฑ์ ±2SD / ±3SD ด้านบนยังเป็นค่าเริ่มต้น พิมพ์ทับเป็นค่าจริงของแต่ละ Parameter ได้เลย ระบบจะตัดสิน Pass/Fail จากค่าที่กรอกไว้ตรงนี้ (เกินขอบ 3SD = Fail)
ไฟล์นี้ซิงก์ผ่านระบบกลาง (Cloudflare Worker) เดียวกับเครื่องมือ Bias — ต้องเปิดไฟล์นี้ตรงๆ (ดับเบิลคลิก หรือโฮสต์เอง) ไม่ใช่ผ่านลิงก์ claude.ai/artifact ถึงจะเชื่อมต่อได้
ข้อมูลเก็บแยกเป็นรายเดือนต่อ QC/Parameter อัตโนมัติ (ตามวันที่ทดสอบ) — เลือก "QC / Parameter" แล้วเลือก "ดูย้อนหลังเดือน" เพื่อดูข้อมูลเดือนก่อนๆ ได้
