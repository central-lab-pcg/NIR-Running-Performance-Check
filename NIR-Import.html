ข้อมูลในระบบ
บันทึกขึ้นระบบอัตโนมัติ (Cloudflare Worker)
ปุ่ม "บันทึก" ส่งข้อมูลผ่าน Worker ซึ่งถือ GitHub token ไว้ให้ ทุกเครื่องใช้ได้เลย ไม่ต้องใส่ token · Dashboard เห็นภายใน ~1–2 นาที
ทางเลือก: ใส่ GitHub token ในเครื่องนี้
ไม่จำเป็นถ้า Worker ด้านบนขึ้น ✅ · ใช้เมื่อ Worker ใช้ไม่ได้ ถ้าใส่ token เครื่องนี้จะเขียนตรงขึ้น GitHub แทน Worker
ถ้าไม่มีทั้ง Worker และ token ระบบจะให้ดาวน์โหลดไฟล์ แล้วไปอัปโหลดเองที่ GitHub
  1. เข้า github.com → Settings → Fine-grained tokens → Generate new token
  2. Resource owner: central-lab-pcg · Repository access: Only select repositories → NIR-Running-Performance-Check
  3. Permissions → Repository → Contents: Read and write → Generate แล้วก็อป token มาวางด้านล่าง

ระบบดู Instrument Serial Number ในไฟล์ IQX/Foss แล้วใส่ Plant / Equipment / Source ให้เอง · เครื่องใหม่จะถูกเพิ่มที่นี่อัตโนมัติตอนบันทึกครั้งแรก
